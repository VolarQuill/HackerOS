## Welcome to HackerOS
This is a tiny webos built in plain HTML, CSS, & JavaScript. Its goal is to make you feel like a hacker.
It has-
1. A search bar
2. live clock
3. a searchbar (google)
4. a notes app
5. popup (also a draggable window)

What i found challenging about this was the notes app. I hadn't done anything as such before. And yes. it is a bit rushed.
